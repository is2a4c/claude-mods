# claude-mods

Плагины Claude Code: `pulse` и `budget`.

## Установка

В терминале Claude Code:

```
/plugin install pulse --marketplace is2a4c/claude-mods
```

Ответить `y` на добавление маркетплейса и выбрать область (user). Для `budget` — та же строка с его именем.

В приложении Claude: `+` рядом с полем ввода → Plugins → Add marketplace с `is2a4c/claude-mods` → Add plugin.

## Плагины

### pulse

Строка у выбора модели: живой баланс DeepSeek и цена текущей сессии в юанях. Все суммы — только в CNY.

Баланс берётся из `https://api.deepseek.com/user/balance` по ключу, который приложение передаёт движку в `ANTHROPIC_AUTH_TOKEN`, когда `ANTHROPIC_BASE_URL` ведёт на `api.deepseek.com`; отдельная настройка не нужна. Обновление раз в минуту. Цена сессии — уменьшение баланса в юанях с начала сессии; списания по тому же ключу из других сессий тоже в неё попадают.

Порог предупреждения — поле `balance_warning_cny` в настройке плагина: когда баланс опускается ниже, показывается тост; `0` выключает. Предупреждение повторяется только после того, как баланс снова поднимется выше порога.

### budget

Журнал расхода в `$.store` и команда `/spend`:

- `/spend` — сегодня, 7 дней, текущая сессия и курс;
- `/spend limit 500` — дневной лимит в рублях;
- `/spend limit off` — снять лимит.

Настройки плагина:

- `daily_limit_rub` — дневной лимит; важнее `/spend limit`, `0` — брать из команды;
- `context_warning_percent` — порог предупреждения о контексте (по умолчанию 75, второй тост на 90), `0` выключает;
- `keep_days` — сколько дней хранить журнал (по умолчанию 30);
- `manual_rate_rub` — фиксированный курс USD/RUB, `0` — курс ЦБ.

Предупреждает тостом при контексте 75% и 90% и при превышении дневного лимита. Курс берёт из хранилища, если он свежий, иначе запрашивает у ЦБ сам.

### deepseek-peak

Перед ответом модели показывает записку, если сейчас peak-часы DeepSeek: Пн–Пт, UTC 01:00–04:00 и 06:00–10:00, кроме государственных праздников КНР. Список праздников 2026–2027 зашит в плагин; при публикации постановления на следующий год его нужно дописать.

## Зависимости

Нет. Оба плагина не запускают процессов и не пишут ничего, кроме собственного ключа в хранилище плагинов.
