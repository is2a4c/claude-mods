# claude-mods

Плагины Claude Code: `pulse` и `budget`.

## Установка

В терминале Claude Code:

```
/plugin install pulse --marketplace is2a4c/claude-mods
```

Ответить `y` на добавление маркетплейса и выбрать область (user). Для `budget` — та же строка с его именем.

В приложении Claude: `+` рядом с полем ввода → Plugins → Add marketplace с `is2a4c/claude-mods` → Add plugin.

## Плагины

### pulse

Строка у выбора модели: живой баланс DeepSeek и цена текущей сессии в юанях. Все суммы — только в CNY.

Баланс берётся из `https://api.deepseek.com/user/balance` по ключу DeepSeek из настройки плагина (`deepseek_api_key`, хранится в защищённом хранилище) и обновляется раз в минуту; без ключа баланс и цена сессии не показываются. Цена сессии — уменьшение баланса в юанях с начала сессии; списания по тому же ключу из других сессий тоже в неё попадают.

### budget

Журнал расхода в `$.store` с хранением 30 дней и команда `/spend`:

- `/spend` — сегодня, 7 дней, текущая сессия и курс;
- `/spend limit 500` — дневной лимит в рублях;
- `/spend limit off` — снять лимит.

Предупреждает тостом при контексте 75% и 90% и при превышении дневного лимита. Курс берёт из хранилища, если он свежий, иначе запрашивает у ЦБ сам.

## Зависимости

Нет. Оба плагина не запускают процессов и не пишут ничего, кроме собственного ключа в хранилище плагинов.
